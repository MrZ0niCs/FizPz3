ИНСТРУКЦИЯ:
Открыв репозиторий проекта, скачать, в Visual Studio указать скачанную папку как проект, в которой находится файл CMakeLists.txt. После запуска дождаться завершения настройки CMake. При первой настройке библиотека SFML загружается автоматически, поэтому требуется подключение к интернету. В списке целей запуска выбрать aabb_demo.exe и нажать Ctrl+F5. Visual Studio соберёт проект и запустит приложение.
Приложение открывает сцену A на паузе. Клавиши 1–4 выбирают соответственно Discrete, CCD, Multi-rate и Pure 240 Гц и сбрасывают начальное состояние. N выполняет один базовый шаг на паузе. Tab переключает сцены, R возвращает исходное состояние, Space управляет паузой, T включает замедленное воспроизведение. Клавиша B запускает бенчмарк с выводом в консоль. Для сравнения двух режимов в сцене A достаточно выбрать каждый из них и нажать N один раз.
